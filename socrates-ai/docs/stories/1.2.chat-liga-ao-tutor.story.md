# Story 1.2 — Chat do aluno ligado ao tutor real

Status: **Done** (validada pelo usuário em produção)
Epic: 1 — Tutor socrático com escada de dicas (Matemática)
Depende de: Story 1.1 (`POST /api/tutor/turn` em produção)

## Story

Como **aluno**, quero conversar com o tutor pelo chat do app, para que as dicas e as explicações venham do servidor e não de textos fixos.

## Escopo

- **Dentro:** `StudentChat` em `app/src/App.tsx` chama `POST /api/tutor/turn`; mostra a fala do tutor; mostra estado de envio e erro com possibilidade de reenviar; o nível de raciocínio vem da resposta (`solved` → 3, demais → 2).
- **Fora:** sessão real com código de entrada (Epic 2), persistência do chat, integração com Gemini (story final).

## Critérios de aceite

1. Ao enviar uma mensagem, o app chama `POST /api/tutor/turn` com `sessionId`, `exerciseId` e a mensagem.
2. A resposta do tutor (`resposta_ao_aluno`) aparece como bolha da IA.
3. Enquanto a resposta não chega, o botão de envio fica desabilitado.
4. Se a chamada falhar, aparece uma mensagem de erro no chat e o aluno pode enviar de novo.
5. "Concluí o desafio!" só aparece quando a resposta trouxer `action: "solved"`.
6. `sessionId` é gerado uma vez por carregamento da tela de chat.
7. `npm run lint`, `npm run typecheck`, `npm run test` e `npm run build` passam a partir de `socrates-ai/`.

## Testes
